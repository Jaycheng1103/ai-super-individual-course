# AI 超級個體實戰｜AI 帶領的課程實作流程

把這份 repo 交給自己的 AI agent，按照課堂順序，從零建立第二大腦、培養 AI 分身的工作能力，完成自己的作品、服務草案與行動計畫。

AI 每次只帶一個階段，說明現在做什麼、需要你提供什麼、完成後如何驗收。訪談回答、作品與進度保存在你的私人工作區；下次可以從上一個斷點接續。完整書稿由講師獨立提供，不是本 repo 的內容或使用前提。

## 如何開始

這份教材已公開，不需要 GitHub 邀請、帳號或登入即可閱讀與下載。把下面這段話貼到自己的 Codex 或能操作本機檔案的 AI agent：

```text
請取得這份公開教材，讀取 AGENTS.md、START_HERE.md 與 course-map.json：
https://github.com/Jaycheng1103/ai-super-individual-course

不需要 GitHub 邀請或登入，請先用公開 HTTPS 下載或 Git clone 取得完整教材。
沿用目前課程專案；若已有教材、第二大腦或進度，先讀回並接續，不覆蓋。
確認專案後，沒有第二大腦就安全安裝 AIS-OS，接著開始訪談。
老師已帶我完成的外掛設定不用重做，首次使用時再驗證；有實際阻塞才請我操作。
依課堂順序一次帶一個階段，訪談一次問一題，保存回答與進度。
個人資料、作品和金鑰放在教材 repo 外的私人工作區，不上傳到公開 repo。
```

AI 會先取得完整教材，再承接目前專案開始。尚未建立專案的自學者，AI 會先帶你建立；課堂已完成專案與 Google 外掛設定的人則直接接續。[下載方式與排錯](docs/get-access.md)

若已下載教材，直接說「請讀 START_HERE.md，帶我開始；有進度就接續」即可。

## 依課堂順序實作

| 順序 | 階段 | 完成標準 |
|---|---|---|
| 01 | [確認課前專案與環境](stages/environment.md) | 沿用目前專案，AI 唯讀確認安裝條件 |
| 02 | [沿用課前外掛設定](stages/connectors.md) | 記錄設定與待實測狀態，不重做連接 |
| 03 | [建立 AI 第二大腦](stages/workspace.md) | 安全安裝 AIS-OS，六個技能及本機讀寫可驗證 |
| 04 | [背景訪談與補足資料](stages/background.md) | 背景、目標與語氣能指回本人確認的資料；未答題與待確認資訊明確保留 |
| 05 | [整理知識與索引](stages/knowledge.md) | 問答能引用正確原件；找不到的答案明確標示不足 |
| 06 | [讓 AI 完成一項日常工作](stages/daily-work.md) | 內容符合指定來源與日期；交付檔案可讀；雲端結果另行驗證 |
| 07 | [安裝行銷與創作能力](stages/skills.md) | Marketing Skills、Agent Reach 與內容三件組可讀；公開資料讀取與內容規劃通過 |
| 08 | [近況訪談與內容三件組](stages/content.md) | 三份草稿均可追溯同一份真實素材；本人至少完整修改一份；待補圖像有標示 |
| 09 | [修正文案語氣](stages/human.md) | 保留原稿與修改理由；沒有添加不存在的故事、數字或承諾 |
| 10 | [Tavily 串接與定位研究](stages/research.md) | 每項主要事實有原始網址與日期；定位與價格提案標為待驗證假設 |
| 11 | [訪談練習與拍攝素材](stages/recording.md) | 自己的原片可播放且聲音可辨識；記錄原片路徑，沒有覆寫原片 |
| 12 | [安裝剪輯工作臺與母版](stages/editor.md) | MCP 狀態與工程列表可讀；母版與自己的素材能在工作臺開啟 |
| 13 | [逐字稿選段與第一輪剪輯](stages/first-edit.md) | 每個選段可回到原片時間碼；本人確認意思與字幕；尚未完成的剪輯明確標示 |
| 14 | [設計自己的變現飛輪](stages/flywheel.md) | 每個環節有具體行動與觀察指標；目標與假設分開，成本及交付工時有列入 |
| 15 | [ElevenLabs 設定與轉錄](stages/transcription.md) | 短音訊真實回傳逐字稿並經本人核對；helper 與剪輯工作臺設定狀態分別記錄 |
| 16 | [完成並驗收第一支影片](stages/first-video.md) | 全片播放與字幕校對通過；工程重開後媒體在線且可編輯 |
| 17 | [建立服務介紹與承接入口](stages/service.md) | 陌生讀者看得懂對象、交付與下一步；入口預覽可讀；公開與付費狀態另記 |
| 18 | [行動計畫、回顧與日常循環](stages/delivery.md) | 每個行動有日期、產物與檢查方式；選出一次真實驗證與一項後續改善 |
| 19 | [依需求選擇延伸工具](stages/optional.md) | 每項分別記錄已測、未測或不使用；未實作的串接不列為已完成 |

前三階段是一次開場處理：承接課前準備，直接在目前專案安全安裝 AIS-OS，再開始訪談。雲端服務等首次使用才驗證。訪談拍攝在剪輯工具之前，變現飛輪討論在第一輪剪輯之後。ElevenLabs 設定完成後增加一次統一的影片驗收，確保作品真的能播放與繼續編輯。最後的行動表是依課程內容設計的課後練習。細節與來源見 [流程依據](docs/course-sequence.md)。
