## AI 帶領步驟

這一階段按需求選做。課堂介紹不代表當天已帶全班從安裝做到成品。

- **OpenSlide**：當天實際分享的是 1weiho/open-slide。依官方 README 使用 `npx @open-slide/cli init my-slide`，再進新專案以 pnpm dev 啟動。先讀目前套件要求；這會安裝並執行 npm 套件，需學員明確要做簡報才執行。驗收是一份可翻頁、可匯出且文字正確的測試簡報。
- **3d-brain／Obsidian**：只有資料索引已可用，再選定允許展示的資料。驗收圖上的節點能回到正確資料，不展示金鑰與客戶個資。
- **Plaud／Fireflies、Canva、Notion、Slack**：依學員原有服務選擇。登入自己的帳號，做指定資料的最小讀取測試。沒有現成帳號就先略過。
- **LINE 官方帳號與 Messaging API**：先到官方開發者文件確認建立方式、channel、webhook、權限與用量。在測試帳號走通「提案 → 本人確認 → 單次發送 → 讀回結果」，不自動發到客戶或班級群。
- **Instagram／Threads／Facebook API**：三者的帳號條件、權限與 token 流程要各別確認，不把一把 token 當全平台通行證。先做唯讀與測試內容，不把全自動公開發布當作預設。
- **Launchill**：課後提到的多平台發布服務，不在本 repo 內代辦購買或承諾權限。原有帳號需要再查看其實際可用功能。

每個選配項目各自記錄已測／未測／不使用，不以安裝完成代替發布成功。官方入口在 resources/links.md。

若這一階段遇到阻塞，保存錯誤種類、已做步驟與下一個動作；不要附上金鑰。完成後依 [接續規則](../START_HERE.md) 保存進度。
