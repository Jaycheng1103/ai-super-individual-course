# 06｜讓 AI 完成一項日常工作

階段 ID：`daily-work`。課堂依據：C4382，02:24–11:33。時間碼為各支影片內位置。

## 現在要做什麼

1. 確認起點、目的地與限制。
2. 整理指定資料，實際打開成果。

## 需要學員提供

- 一份可用的會議記錄或工作文件。
- 希望交付的格式與位置。

## AI 帶領步驟

先確認 Codex 與 Claude Code 若要共用工作，開啟的是同一個私人資料夾。讀它的 AGENTS.md／CLAUDE.md；只使用一個 agent 也可以，不必兩個都訂閱。

請學員指定一份會議或工作文件，說明「目前有哪些資料、想交付什麼、給誰看、有什麼限制」。課堂示範是 Plaud 指定日期的會議整理成 PDF，再放到 Drive。

若這是第一次實際使用雲端連接，先核對能否讀取這份指定資料與內容；課前已設定不等於已通過功能實測，失敗才修復該項連接。

AI 先讀來源及日期，整理決策、待辦與不確定事項，讓學員核對；有 PDF 能力時輸出 PDF 並打開檢查。學員沒有 Plaud 時，使用自備會議文字或中性測試文件，明確記錄替代路徑，不要求新訂閱。

指定雲端交付且已獲授權才上傳到本人選定的資料夾，再讀回檔案與存取方式。若無 PDF／Drive 能力，保留可讀的本機摘要，把未驗證能力列出，不假稱完成雲端流程。

## 留下什麼、做到什麼才算完成

建議檔案：`outputs/daily-work/summary.md`。已有自己的命名與結構就沿用，在進度中記錄實際位置。

- 內容符合指定來源與日期。
- 交付檔案可讀；雲端結果另行驗證。

## 中途停下來

每完成一個動作或收到一題回答，就保存實際檔案、目前步驟、下一個動作與阻塞原因。訪談另外保存下一題；檔案與答案留在私人工作區。恢復時先讀這些記錄，再接續，不重跑已驗收的步驟。命令見 [START_HERE](../START_HERE.md)。
