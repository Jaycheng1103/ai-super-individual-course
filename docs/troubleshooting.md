# 常見問題與恢復方式

| 問題 | 下一步 |
|---|---|
| 教材顯示 404 | 核對公開網址與網路；改用公開 HTTPS 或 ZIP，不需要接受邀請 |
| 沒有 python3 | 從 Python 官方安裝 3.10 以上；Windows 試 `py -3`，重開終端 |
| Python HTTPS 憑證錯誤 | 使用官方 Python 安裝器附的憑證修復說明或更新系統憑證；不關閉 TLS 驗證 |
| SHA-256 不符 | 停止安裝，保留錯誤；請講師重新核驗固定版本，不略過完整性檢查 |
| 目的地已存在 | 新課程專案使用 init --in-place；已有第二大腦或同名衝突則依 existing-workspace.md 接入，不刪資料 |
| 同名 Skill 版本不同 | 請 AI 比較差異、保留客製版，再決定安裝位置；不能用 force 靜默覆蓋 |
| 檔案已裝，AI 看不到 | 重開專案／對話，確認目前 agent 技能路徑；讀回實際檔案，不只看安裝訊息 |
| Skill 的跨資料夾連結不存在 | 到私人工作區 .course/sources 的同一固定版本查原檔，記錄上游缺鏈；不另抓不明網站的同名工具 |
| Tavily／ElevenLabs 401 或 403 | 本人檢查金鑰是否有效及權限範圍，不公開 key；只記 HTTP 狀態 |
| API 429、額度不足 | 查看自己的用量與方案，暫停測試；不自動加值或連續重試 |
| OpenChatCut MCP 連不上 | 先開應用、確認本機端點、所用 agent 設定，再看官方 getting-started 文件 |
| 系統擋住 App | 由本人查看來源與官方支援；不要停用安全功能或叫 agent 繞過警告 |
| 模板無講師影片 | 教學母版本來不含私人影片，請匯入自己的測試素材 |
| 影片匯出後字幕錯誤 | 回到來源時間碼聽原音，再改字幕並重新驗收，不用整支重裝 |
| 換電腦 | 搬自己的資料與可攜工程，重新安裝 agent／工具並授權；逐項測試 API，勿假定登入會一起搬過去 |

第三方套件以 sources.lock.json 固定版本。上游更新不會自動改動學員工作區；教材更新後，先比較版本再決定是否升級。

本 repo 的 credential helper 將金鑰放在 `.course/secrets` 本機檔案。macOS／Linux 會要求私有檔案權限，但這不是加密；Windows 請使用自己的使用者資料夾，避免共用同步。更成熟的工作流程可改用 agent 原生安全設定或作業系統憑證儲存。

原課堂示範曾用剪貼簿描述 API 設定，本教材改成學員本人在安全設定或不回顯終端輸入。這不影響學習用途，也避免把 key 留進對話。

## v2 進度接續

舊版第一次 status 會保存 v1 備份並標 needs_review。先核對作品再恢復完成狀態，不因改版重新安裝。start 後到 init 前只在 .course 內放筆記；若在工作區根目錄已有其他檔案，停止自動初始化，依既有工作區流程手動比較，不刪掉學員資料來通過檢查。

課堂預設沿用目前已建好的 Codex 專案。init --in-place 在全部同名項目檢查通過後才寫入，檢查到衝突不會先裝一半。環境造成的執行中斷仍須讀回狀態再恢復，不強制重新初始化。
