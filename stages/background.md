# 04｜背景訪談與補足資料

階段 ID：`background`。課堂依據：C4378，07:14 起；C4379；C4380，02:10 起。時間碼為各支影片內位置。

## 現在要做什麼

1. 依 onboard 七個主題逐題訪問。
2. 本人核對背景，再以 audit、grill-me 補缺口。

## 需要學員提供

- 本人背景與近期目標。
- 1–2 份本人文字樣本。

## AI 帶領步驟

留下的成果：本人核對過的背景、語氣樣本、近期目標與工作來源。

先讀 AIS-OS 的 onboard Skill。從「你是誰、提供什麼、服務誰」開始，一次只問一題。依實際回答整理工作背景；沒有的資料就保留待補，不替學員編出產品、收入或客戶成果。

依 onboard 原有流程核對七個主題：① 身份與服務，② 本人文字樣本，③ 近期目標，④ 收款與工作記錄方式，⑤ 客戶溝通，⑥ 會議與文件來源，⑦ 最耗時的工作。每次只問目前缺的一題，等回答後才往下。這裡只需要工作流程，不索取帳密或金鑰。

每題回答保存到私人 `.course/interview.md`，記錄題號、本人回答摘要、已確認／待確認，以及下一題。更新正式背景文件前先核對；下次先讀訪談紀錄，不重新問已答完的七題。學員選擇不回答的項目，記錄略過及其影響。

接著蒐集 1–2 份學員真的寫過的文字作為語感來源，詢問近期目標、收款與記錄方式、溝通工具、會議文件來源、最耗時工作。只記錄系統名稱與流程，不收集密碼、完整帳號或客戶私訊。

讀回 context/about-me.md、about-business.md、priorities.md、references/voice.md、connections.md，讓本人訂正。再用 audit 找實際缺件，用 AIS-OS grill-me 深入一個問題。分數不是成績，缺的證據比追求滿分重要。

課堂另分享 Matt Pocock 訪談套件。需要深入釐清計畫時，可另安裝：

```sh
python3 scripts/course.py install --workspace "../my-ai-workspace" --component interview --agent codex
```

Claude Code 將 codex 改成 claude-code。本版安裝名稱為 grilling；不覆蓋 AIS-OS 的 grill-me。第三方原始 grill-me 目前只是轉接至 grilling，不能只安裝那個別名檔。

驗收：問 AI「我服務誰、這個月優先做什麼、我會怎麼說話」，每項能指回實際文件；未確認事項明確標示。

若這一階段遇到阻塞，保存錯誤種類、已做步驟與下一個動作；不要附上金鑰。完成後依 [接續規則](../START_HERE.md) 保存進度。

## 留下什麼、做到什麼才算完成

建議檔案：`context/about-me.md`、`references/voice.md`、`.course/interview.md`。已有自己的命名與結構就沿用，在進度中記錄實際位置。

- 背景、目標與語氣能指回本人確認的資料。
- 未答題與待確認資訊明確保留。

## 中途停下來

每完成一個動作或收到一題回答，就保存實際檔案、目前步驟、下一個動作與阻塞原因。訪談另外保存下一題；檔案與答案留在私人工作區。恢復時先讀這些記錄，再接續，不重跑已驗收的步驟。命令見 [START_HERE](../START_HERE.md)。
