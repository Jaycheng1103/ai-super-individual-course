原錄影的順序為「先連接再建庫、背景訪談後做實作、先拍攝再剪輯、第一輪剪輯後討論飛輪、再設定 ElevenLabs 與服務入口」。課堂入口已依下方講師確認調整。課堂反覆切換實作與問答，本 repo 將相關動作拆成可接續的階段。

first-video 是在 ElevenLabs 後新增的統一驗收點，確保沒有只停在工具設定。第一輪剪輯若缺轉錄能力，先用人工核對文字練習選段，留下阻塞，設定完成後接回工程。delivery 的週行動表、檔案命名、三份知識來源及逐步驗收是為課後獨立實作設計，不宣稱當天每位學員都逐項完成。

OpenSlide、LINE 與社群 API 保留為選配介紹，需要時另按官方文件設定；不宣稱課堂已帶完全部串接。完整書稿、原始影音與私人對話不放在這個 repo。

## 課堂入口調整

依講師後續確認，Codex 專案建立與 Google 外掛手動連接已在課前帶完。新版承接這個起點，前三階段由 AI 一次檢查、安裝及回填，接著直接訪談。這是明確的課程流程調整；不再要求學員重做課前操作或先提供三種測試資料。雲端功能驗證移到首次實際使用時。
