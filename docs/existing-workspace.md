# 已有第二大腦時怎麼接入

已經有第二大腦、工作規則或同名技能時，不執行整包 init 覆蓋。若只是講師剛建立的課程專案，則可依 workspace 階段使用 init --in-place；它會先核對所有衝突，沒有衝突才新增檔案。

1. 學員指定既有工作區，AI 先讀它的 AGENTS.md／CLAUDE.md，確認正式資料、語氣、來源與技能位置。
2. 列出缺的課程能力與同名技能，不把檔案少或名字不同判定為沒做。
3. 在 repo 外的另一個全新測試資料夾執行 init 與需要的 install，取得鎖定版本的完整包。
4. 比較新舊 SKILL.md、references、assets 及客製內容，保留原版。已確認需要的部分再由 AI 安裝到目前 agent 的專案技能位置；不要把測試資料當成真實背景。
5. 在既有工作區建立私人學習進度記錄，可使用 templates/progress.md。course.py 只管理它自己建立的工作區；不要偽造 marker 讓 helper 強行改既有庫。
6. 每個技能做一次小任務與讀回。原本已經完成的背景訪談可重用，缺的問題再補，不強迫重答七題。

AIS-OS 的六個技能已具備背景、索引、檢查與改善方法。同名的第三方 grill-me 不應直接取代；本課程另取 Matt Pocock 的 grilling 作為選用訪談技能。
