# 13｜逐字稿選段與第一輪剪輯

階段 ID：`first-edit`。課堂依據：C4387；C4388，00:00–05:19。時間碼為各支影片內位置。

## 現在要做什麼

1. 產出忠實逐字稿或先用人工校對文字。
2. 選段、試剪並預覽字幕與標題。

## 需要學員提供

- 原片與預期觀眾。
- 想保留的意思與長度。

## AI 帶領步驟

先用 openchatcut-talking-video 讀指定原片，整理含時間碼的逐字稿與選段表：原句、建議保留或刪除、原因。學員確認意思與順序後才剪，保留原工程副本。

有已授權的轉錄能力就使用。若工作臺要求尚未設定的 ElevenLabs，記下阻塞，先用人工校對的短片文字與時間碼練習選段、標題及字幕，稍後在 transcription 階段接回；不可假稱語音 API 已通過。

本人預覽一輪，提出一項具體修改。此步驗收的是能說明選段及修改方向；付費轉錄或工程編輯仍卡住時，在進度留下待處理項目。first-video 會補齊完整輸出驗收，不能把選段表當成完成影片。

## 留下什麼、做到什麼才算完成

建議檔案：`outputs/video/edit-plan.md`、`outputs/video/transcript.md`。已有自己的命名與結構就沿用，在進度中記錄實際位置。

- 每個選段可回到原片時間碼。
- 本人確認意思與字幕；尚未完成的剪輯明確標示。
