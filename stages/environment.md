# 01｜確認方向與準備環境

階段 ID：`environment`。課堂依據：C4376，00:00、33:32、42:37 起。時間碼為各支影片內位置。

## 現在要做什麼

1. 記錄目前專案與可用工具。
2. 沿用目前專案，確認私人進度位置。

## 需要學員提供

- 作業系統、agent、是否已有第二大腦。
- 只有無法判定目前專案位置時，才需要學員補充。

## AI 帶領步驟

此階段承接講師已建立的 Codex 專案，由 AI 做簡短的唯讀檢查，不另開一輪環境問答。

1. 先讀教材並確認目前專案位置，沿用已知 OS、agent。檢查能否讀寫課程專案與執行 Python 3.10 以上；缺工具才處理。
2. 確認學生專案與教材 repo 是不同目錄。教材可放專案內獨立子目錄；若開啟的是教材根目錄，才詢問課前建立的專案位置。
3. 查看已有 AIS-OS 或進度，有就接續；沒有就直接進 workspace 安裝。同時依 connectors 記錄課前準備，無須先測三項雲端服務。
4. AIS-OS 安裝成功後把環境證據回填到 .course。學習目標留到 onboard 訪談中詢問，不在開場重複問。

尚未做課前準備的自學者，才選 repo 外的全新私人專案。Typeless 或系統聽寫需要時再確認，不擋住開始訪談。

## 留下什麼、做到什麼才算完成

建議檔案：`.course/learning-brief.md`。已有自己的命名與結構就沿用，在進度中記錄實際位置。

- AI 能讀教材與私人測試檔。
- 已確認目前專案位置，可承接 AIS-OS 安裝。

## 中途停下來

每完成一個動作或收到一題回答，就保存實際檔案、目前步驟、下一個動作與阻塞原因。訪談另外保存下一題；檔案與答案留在私人工作區。恢復時先讀這些記錄，再接續，不重跑已驗收的步驟。命令見 [START_HERE](../START_HERE.md)。
